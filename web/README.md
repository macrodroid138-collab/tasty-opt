# Sigma desk

The screen for Sigma Carry and Sigma Clip. Demo replays five saved sessions. Live reports whether the Tastytrade production credentials are present and does not send an order from this page. The programs that do send orders are `programs/sigma-carry` and `programs/sigma-clip`.

```
npm install
npm run dev
```

The desk listens on port 4317. The rules are in `../MANIFESTO.md`.
